# SEO & Web Accessibility

## Web Designing Experiment 4

This project demonstrates how to optimize a webpage for SEO and accessibility using semantic HTML, proper heading structure and meta tags.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- Bootstrap Icons

## Features

- SEO meta tags
- Semantic HTML5
- Proper heading hierarchy
- Accessibility support
- ARIA labels
- Keyboard navigation
- Skip-to-content link
- Responsive design
- Dark/Light mode
- Animated counters
- Progress bars
- Scroll reveal animation
- SEO checker
- Accessibility checker
- Copy code feature
- Toast notifications
- Mouse glow effect
- Back-to-top button
- Mobile navigation
